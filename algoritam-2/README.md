# АЛГО-01 — Алгоритъм под контрол 2.0

Интерактивна образователна игра за 10. клас по ИТ: „Алгоритми. Свойства на алгоритмите“.

## Онлайн адрес

https://algo-01-classroom.onrender.com

## За учениците

1. Отворете адреса в браузър.
2. Въведете **псевдоним**, без фамилия или имейл.
3. Ако учителят е дал код на стая, въведете го; иначе играйте самостоятелно.
4. Изпълнете последователно петте мисии. Отговорите се проверяват на място.
5. На края отворете „Моят резултат“ и изтеглете JSON отчет или принтирайте сертификат.

Личният напредък се пази и в този браузър (localStorage), докато данните не се изтрият.

## За учителя

1. Отворете „За учителя“ → „Създай класна стая“.
2. Покажете шестсимволния код на дъската или споделете линка.
3. Учениците въвеждат псевдоним и кода. Не се изискват регистрации.
4. Таблицата с резултати се обновява периодично; може да видите финалните алгоритми.
5. **Експортирайте CSV преди края на часа**. CSV се отваря в Excel.

## Ограничение на безплатния Render план

За да избегнем акаунти, събиране на реални лични данни и разходи за база данни, текущата версия съхранява *общите* данни на учителската стая **само в оперативната памет на сървъра**. Онлайн стаята изтича след максимум 48 часа и може да се изгуби при рестартиране, заспиване или ново внедряване. За постоянни отчети са необходими база данни и съответните мерки за защита. Отделният ученически прогрес остава записан локално. Не използвайте тези точки за автоматично поставяне на училищни оценки.

## Стартиране локално

Изисква Python 3, без външни зависимости:

```bash
PORT=10000 python algoritam-2/server.py
```

Windows PowerShell:

```powershell
$env:PORT=10000; python .\algoritam-2\server.py
```

Отворете http://localhost:10000.
