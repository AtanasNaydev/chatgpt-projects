# Учебни проекти

Това хранилище съдържа код за учебни приложения.

## МИСИЯ 404: Дигитален хаос

Интерактивно упражнение по информационни технологии за 10. клас.

Кодът за онлайн публикуване е подготвен във файл **Misiya_404_Render_Gotova_za_Publikuvane.zip**. Разархивирайте файла и качете папката като `misiya404-render/`. Не качвайте локални файлове `teacher_config.json`, `game_data.json` или `.env`.

Използва Python и PostgreSQL. Публикуването в Render се извършва само след качване на кода и настройка на безплатен уебсървър с постоянна база данни. Секретният учителски код трябва да се задава чрез Environment Variables, а не в GitHub.
